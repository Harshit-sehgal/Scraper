Frequently asked questions

What websites can Dataforge scrape?

Dataforge works with any publicly accessible page. For sites behind login, use Auth Profiles to store and replay browser sessions.

How is Dataforge different from BeautifulSoup or Scrapy?

Dataforge is schema-first and intent-driven — you describe what data you want, not how to extract it. The engine handles discovery, pagination, deduplication, and retry automatically.

Is there rate limiting?

Yes. Dataforge has a built-in rate limiter with per-domain backoff and operators can choose production, benchmark, forensic, resilient, or low-cost modes to tune behavior.

Can I export data to my pipeline?

Absolutely. Export as CSV, JSON, or Excel. The REST API also supports streaming results for real-time pipelines.

Is my data secure?

All data is encrypted at rest and in transit. API keys are HMAC-verified. Every action is audited. Tenant isolation is enforced at the API layer.

Do I need to write code?

No. The web UI lets you define schemas, run jobs, and export results — no code required. For advanced use, the REST API offers full programmatic control.
